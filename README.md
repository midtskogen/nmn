# Norsk meteornettverk (NMN) — All Sky7 Software

This repository contains the software that runs the Norsk meteornettverk (NMN), a network of All Sky7 (AMS/AllSky7) meteor camera stations in Norway. It handles station health monitoring, real-time meteor detection, video and image processing, orbit/trajectory calculation, web reporting, and live all-sky imagery.

## Repository Layout

```
.
├── bin/          # Station-side command-line tools and processing scripts
├── server/       # Web backend, public API, and live website generator
├── server/data/  # Live web application (controller.py, obs.html, API handlers, assets)
├── model/        # Machine-learning model files for meteor detection/classification
├── src/          # C source code for compiled helper programs
└── .clang-format # Formatting rules for C/C++ code
```

## Main Components

### `bin/` — Station Tools

Scripts used directly on each camera station and for offline processing:

- **`as7health.py`** — Comprehensive station health audit. Checks mounts, cloud archive, network, syslog, OOM events, segmentation faults, and more. Run with `--nmn` for NMN-wide checks.
- **`stitcher.py`** — All-sky image/video stitcher. Reprojects multiple camera views into a single panorama, supports equirectangular/fisheye output, vignetting correction (`--devignette`), and seamless tiling.
- **`metrack.py`** / **`centroid2event.py`** / **`classify.py`** — Meteor track extraction, event centroiding, and ML-based classification.
- **`calibrate.py`** / **`amscalib2lens.py`** / **`pto2amscalib.py`** — Camera calibration, lens parameter conversion, and PTO handling.
- **`fetch.py`** — Fetches event data from remote stations, computes trajectories/orbits, generates plots and translated HTML/KML reports.
- **`report.py`** / **`orbit.py`** / **`showerassoc.py`** — Report generation, orbit determination, and meteor shower association.
- **`makevideos.py`** / **`timelapse*.sh`** / **`stack.py`** — Video, timelapse, and image stacking utilities.
- **`setconf.sh`** — Station configuration helper.
- **`ams2event.py`** — Converts AMS detection files to NMN event format.

### `server/` — Web Backend and Central Services

- **`server/fetch.py`** — Central data fetcher that pulls observations from stations and produces web reports.
- **`server/merge_events.py`** — Merges multi-station observations into single events.
- **`server/classification.py`** / **`false.py`** — Classification and false-positive filtering.
- **`server/data/controller.py`** — Live website controller (symlinked on the live web server `bolide`).
- **`server/data/obs.html`** — Main live observation map/page.
- **`server/data/api.js`** / **`main.js`** / **`chart_handler.js`** — Frontend JavaScript and API handlers.
- **`server/data/media_processor.py`** / **`live_streamer.py`** — Media processing and live streaming.

### `model/` — Machine Learning

- **`meteor_efficientnet_b0_model_clustered.pth.zst`** — Compressed EfficientNet-B0 model used for meteor/non-meteor classification.

### `src/` — Legacy C Code

- **`metdetect.c`** — Fast meteor detection helper.
- **`parsexy.c`** — Star/plate coordinate parser helper.

> **Note:** The C code in `src/` is legacy code that is no longer built or used by the current pipeline. It is kept for reference only.

## Quick Start

### Station Health Check

Run from a station as `root`:

```bash
python3 /home/meteor/nmn/bin/as7health.py --nmn
```

Run the full set of station-only checks:

```bash
sudo python3 /home/meteor/nmn/bin/as7health.py
```

### All-Sky Image/Video Stitch

```bash
python3 /home/meteor/nmn/bin/stitcher.py --help
python3 /home/meteor/nmn/bin/stitcher.py /path/to/cal/files /path/to/images --equirect
```

### Calibration

```bash
python3 /home/meteor/nmn/bin/calibrate.py --help
python3 /home/meteor/nmn/bin/amscalib2lens.py --help
```

## Dependencies

The code is written for Python 3 and uses a mix of standard and scientific libraries:

- NumPy, SciPy, Pillow
- Numba (used heavily in `stitcher.py`)
- OpenCV (often imported as `cv2`)
- Paramiko (for remote health checks)
- matplotlib / basemap (for plots)
- PyTorch (for model inference)

Specific scripts will warn at runtime if an optional dependency is missing.

## Development Notes

- **Numba cache poisoning:** Importing modules as `from nmn.bin import multiblend` can poison Numba's on-disk bytecode cache. If you see strange Numba errors, run:
  ```bash
  rm -rf nmn/bin/__pycache__
  ```

## Configuration

Station-specific settings live outside this repository on each host (e.g. `/home/ams/amscams/conf/...`, `/etc/meteor.cfg`). The `setconf.sh` and `as7health.py` scripts check these files and report problems if they are missing or inconsistent.
