NMN Public API

REST API for the Norsk Meteornettverk data services. It mirrors the services provided by the data/ web interface.

Base URL: /api/v1 OpenAPI 3 Swagger UI OpenAPI YAML

Authentication

  • Read-only endpoints are public and limited by IP.
  • Downloads, streams and station-traffic endpoints require an API key in the X-API-Key header.
  • Contact Norsk Meteornettverk to request access to protected endpoints.
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/downloads

Rate and traffic limits

  • Public read-only: 100 requests/min and 1000/hour per IP.
  • Authenticated stateful: 20 requests/min and 200/hour per key (configurable per key).
  • Downloads share the same daily quota as the web UI: 2 GB total / 1 GB per site.
  • Streams share the same per-IP daily stream-time quota as the web UI.
  • Grid / annotation / archive overlay fetches count against the download quota.

When a limit is exceeded the API returns HTTP 429 with a Retry-After header.

Asynchronous operations

Predictions and image enhancement return 202 Accepted with a task ID. Use the returned poll_url until the status becomes complete or error.

# Start a prediction
curl -X POST 'https://norskmeteornettverk.no/api/v1/predict/passes?station=ams173&days=3'

# Poll the returned task
curl https://norskmeteornettverk.no/api/v1/predict/passes/pass_task_...

Example requests

Read-only data

# List all stations
curl https://norskmeteornettverk.no/api/v1/stations

# Camera fields-of-view
curl https://norskmeteornettverk.no/api/v1/cameras/fovs

# Aurora KP index
curl https://norskmeteornettverk.no/api/v1/kp

# Lightning for a specific date
curl 'https://norskmeteornettverk.no/api/v1/lightning?date=2026-08-31'

# Meteor events
curl https://norskmeteornettverk.no/api/v1/meteors

# Station statistics for a date range
curl 'https://norskmeteornettverk.no/api/v1/stations/ams173/stats?start_date=2026-08-01&end_date=2026-08-31'

Predictions (asynchronous)

# Satellite passes, one station, last 3 days
curl -X POST 'https://norskmeteornettverk.no/api/v1/predict/passes?station=ams173&days=3'

# Satellite passes for all stations in a time window
curl -X POST 'https://norskmeteornettverk.no/api/v1/predict/passes?start=2026-08-31T00:00:00Z&end=2026-09-03T00:00:00Z'

# Aircraft crossings
curl -X POST 'https://norskmeteornettverk.no/api/v1/predict/aircraft?station=ams173&days=2'

# Response:
# {"task_id":"pass_task_1725...","status":"queued","poll_url":"/api/v1/predict/passes/pass_task_1725..."}

# Poll until status is complete or error
curl https://norskmeteornettverk.no/api/v1/predict/passes/pass_task_1725...

Downloads (requires API key)

The simplest form needs no JSON — everything is a query parameter on a single URL:

# One image from camera 1 at 20:00 UTC
curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/download?station=ams173&camera=1&date=2026-08-31&hour=20&minute=0&file_type=image'

# A sequence of 5 images, 5 minutes apart
curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/download?station=ams173&camera=1&date=2026-08-31&hour=20&minute=0&file_type=image&length=5&interval=5'

# A 3-minute low-res video
curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/download?station=ams173&camera=1&date=2026-08-31&hour=20&minute=0&file_type=lowres&duration=3'

# Both timelapse projections for two days (camera/hour/minute not needed)
curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/download?station=ams173&date=2026-08-31&file_type=timelapse&length=2&stitch_equirect=1&stitch_fisheye=1'

# Response:
# {"task_id":"master_task_...","status":"pending","poll_url":"/api/v1/downloads/master_task_..."}
#
# Poll until "status":"complete" — "files" then holds direct URLs like
# download/SOR_cam2_20260918_0004_image_lowres.jpg under /data/
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/downloads/master_task_1725...

Parameters: station (comma-separated amsNNN, max 10), camera, date (YYYY-MM-DD), hour, minute (UTC), file_type (lowres|hires|image|image_lowres|image_long|image_lowres_long|timelapse|timelapse_hires), length, interval, duration, stitch_equirect, stitch_fisheye, lang.

The advanced form accepts the same fields as a JSON body (plus pass_data/flight_pass_data/crossing_data for pass downloads):

curl -X POST https://norskmeteornettverk.no/api/v1/downloads \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -d '{"stations":["ams173"],"cameras":[1],"file_type":"image","date":"2026-08-31","hour":"20","minute":"0","length":5,"interval":5}'

# Cancel / cleanup
curl -X DELETE -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/downloads/master_task_1725...

Live streams (requires API key)

# Start a low-resolution stream on camera 1
curl -X POST 'https://norskmeteornettverk.no/api/v1/streams' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -d 'station_id=ams173&camera_num=1&resolution=lowres'

# Poll status
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/streams/stream_1725...

# Request H.264 transcoding for browsers without HEVC support
curl -X POST -H 'X-API-Key: YOUR_API_KEY' \
  https://norskmeteornettverk.no/api/v1/streams/stream_1725.../transcode

# Stop the stream
curl -X DELETE -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/streams/stream_1725...

Overlays (requires API key, counts against download quota)

# Live stream overlays
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/grids/ams173/1
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/annotations/ams173/1

# Archive overlays for a specific timestamp
curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/archive/grid?station_id=ams173&camera_num=1×tamp=2026-08-31T20:00:00Z'

curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/archive/annotation?station_id=ams173&camera_num=1×tamp=2026-08-31T20:00:00Z'

curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://norskmeteornettverk.no/api/v1/archive/mask?station_id=ams173&camera_num=1×tamp=2026-08-31T20:00:00Z'

Image enhancement (asynchronous)

curl -X POST https://norskmeteornettverk.no/api/v1/enhance \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -d '{"image": "download/ams173_20260831_200000.jpg", "filter": 30}'

# Poll the generic task endpoint
curl -H 'X-API-Key: YOUR_API_KEY' https://norskmeteornettverk.no/api/v1/tasks/api_task_1725...

Error responses

Missing API key on a protected endpoint:

{"error":"missing_api_key","message":"This endpoint requires an API key in the X-API-Key header."}

Rate limit exceeded:

{"error":"rate_limit_exceeded","message":"Too many requests. Please slow down.","retry_after":42}

The HTTP status is 429 and a Retry-After header is included.

For the full interactive spec, open Swagger UI.
